# Analytics and privacy

This site uses Cloudflare Web Analytics to understand site usage and page performance.

Anonymous, aggregated metrics include page views, visits, pages viewed, referrers, country, device, browser, operating system, and page performance. The site does not collect names, email addresses, or other information that identifies individual visitors.

Cloudflare Web Analytics does not use cookies, localStorage, sessionStorage, or cross-site tracking. See [Cloudflare's data collection documentation](https://developers.cloudflare.com/web-analytics/data-metrics/data-origin-and-collection/) for details.
