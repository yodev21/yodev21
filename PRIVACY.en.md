# Analytics and external data transmission

This site uses Cloudflare Web Analytics to understand site usage and page performance and to improve the site.

## Information sent externally

When a page loads, the page hostname and path, referrer, country, device type, browser, operating system, navigation type, and page performance data are sent to Cloudflare, Inc. URL query strings are not logged.

The destinations are `static.cloudflareinsights.com` and `cloudflareinsights.com`. The information is used to aggregate page views, visits, referrers, browsing environments, and performance so the site structure and content can be improved.

## Cookies and retention

Cloudflare Web Analytics does not use cookies, localStorage, or sessionStorage and does not track visitors across different sites. The site operator does not receive visitor names or email addresses.

Cloudflare states that raw beacon data is retained for seven days before aggregation, and aggregated dashboard data remains available for six months. No analytics data is sent if JavaScript is disabled or the analytics script is blocked.

See <a href="https://developers.cloudflare.com/web-analytics/data-metrics/data-origin-and-collection/" target="_blank" rel="noopener">Cloudflare's Web Analytics data collection documentation</a> and <a href="https://www.cloudflare.com/privacypolicy/" target="_blank" rel="noopener">Cloudflare's privacy policy</a> for details.
